# Figure inputs and generation

Run `python -m regenate.visualization.generate_all_figures --campaign runs/oracle_v1 --out reports/figures` with `src` on PYTHONPATH. The generated `reports/figures/INDEX.md` records each input and boundary; missing data are marked NOT_VERIFIED. F01, F02 and F11 need unavailable DS05 prediction rows.

F03 uses DS05 skill versus the previous cycle at each power horizon; F04 uses one-step power skill against persistence for DS02/DS04 (mean over dataset subsets), and previous-cycle skill for DS05 sink. Model identifiers differ between datasets. F05 contains datasheet points (VENDOR_REPORTED). F06 compares the recorded S3 ORACLE and B1p-OPT series on the same instance and flexibility; direct transfer is topology-specific. F07 summarizes twin control voltage extrema, including rejected cases. F08 uses the S3 rolling ladder, paired against B1 with bootstrap intervals; inspect tardiness and constraints separately. F09 transcribes AI-EXP12, with DS05-derived simulated profiles and assumed station scaling and windows. F10_grid shows the available S3 grid cells; blank cells are missing, not zero. F12 uses DS05 80% interval coverage. F13 uses the recorded S3 schedules. F14 displays grid import and export for one rolling P instance, not a full energy ledger. F15 matches DS05 model accuracy and measured prediction time for sink power at one slot.

F10 and F10b use the completed sensitivity campaign in runs/sens_v1/sensitivity_results.csv. F10 compares S3 gain (B1p-OPT minus ORACLE at M0) in kWh and percent across one-at-a-time sweeps, with paired 95% confidence intervals and the S1 zero control.
