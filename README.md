# ReGenATE

ReGenATE is a research prototype for production-constrained coordination of regenerative power in a reference battery-cycling cell. The primary metric is incremental grid energy at M0 against regenerative-to-AC B1, under matched constraints. The default scheduler is P0-E1-Peak; learned ETA is advisory. Semiconductor transfer and site benefits remain NOT_VERIFIED. Source: `docs/decisions.md` D019?D021; `reports/final/Run4_Final_Evaluation_Report.md`.
